# GRIP PRO: CHANNEL 13

A destructive toon arcade racer by **Razorbill Studio**, built in Unity for Windows and macOS.

Somewhere off the map, an illegal street league races for a pirate stream called **Channel 13**. You're the rookie driver for **Grip Pro**, a crew famous for turning ordinary cars into monsters. Every drift, knock and roll is broadcast live. Chat reacts, viewers pile in, and the stream pays out in **Hype**. The crew flies cars in and out by heavy-lift helicopter, one step ahead of the police.

![Main menu](docs/media/menu-d-home-final.png)

## What makes it different

- **The whole game is the broadcast.** Menus, HUD and results are dressed as the pirate stream: a LIVE tag, a viewer count that reacts to your driving, a chat column called The Feed carrying story posts, news and rumours, and fan dares that pop up mid-race.
- **Style pays as much as winning.** Hype comes from placing and from how you drive: drift tiers, chain knocks, clean landings and dares, all multiplied by a streak that cools off if you drive dull.
- **Moves you can't do in other racers.** Spiral barrel rolls left and right to dodge, a forward spiral roll into slower cars, rolling off walls you're riding, and knocks that send rivals tumbling into each other.
- **Cars feel like they look.** Six cars, each with a type (All-rounder, Supercar, Race car, Muscle, Tuner, Heavy) that sets its drift character (Drifty, Balanced or Grippy).

## Controls

| Key | Pad | Action |
|---|---|---|
| W / S | Triggers | Accelerate, brake and reverse |
| A / D | Left stick | Steer |
| Space | | Handbrake. Hold through a corner to drift, let go to cash the boost |
| Left Shift or Left Ctrl | | Nitro |
| Q / E | LB / RB | Spiral roll left / right |
| Q + E | LB + RB | Forward spiral roll |
| R | | Reset car |
| Esc | Start | Pause |

In the menus: A / D or arrows to move, Enter to select, Esc to go back. Drag with the mouse (or use the right stick) to orbit the car.

## Tech

- Unity **6000.3.10f1**, Universal Render Pipeline (Forward+), Input System
- Realistic Car Controller Pro behind the game's own vehicle interfaces (`IVehicle`, `IDriftInput`, `INitroTank`), so the moves and drift work on the car's Rigidbody and don't depend on the controller
- Menus, HUD, the menu backdrop and the cars are generated by editor builders, so every screen can be rebuilt from code:
  - **SHIFT RUSH > Build Main Menu** (menus, loading screen, pause menu, race HUD, backdrop)
  - **SHIFT RUSH > Build Race HUD**
  - **SHIFT RUSH > Build Menu Showcase** (the night airstrip behind the car)
  - **SHIFT RUSH > Cars > Car Setup** (car type, drift character and moves for each car)
- Project code lives in `Assets/_ShiftRush/`

## How it's made

Razorbill Studio designs, directs, tunes and play-tests every part of the game: the concept and story, the mechanics and how they should feel, the hand-tuned drift values, the choice of art and packs, and every look and layout decision. The code and UI are built with **Claude Code**, an AI coding assistant, working from that direction. The devlog notes who decided what.

## Third-party packs (not in this repo)

These paid packs are git-ignored because their licences don't allow the files to be shared. To open and build the project, buy and import each one into `Assets/` at its default location.

| Pack | Store | Used for |
|---|---|---|
| Realistic Car Controller Pro (BoneCracker Games) | Unity Asset Store | Vehicle physics, AI racers |
| ARCADE – Ultimate Vehicles Pack | Unity Asset Store | Cars and the Aglaea helicopter |
| Spline Architect + Terrain Tools | Unity Asset Store | Track and terrain |
| POLYGON Alpine Mountain – Nature Biomes (Synty) | Synty Store | Alpine scenery |
| KROMA – Atmosphere Toolkit (URP) | Unity Asset Store | Sky, rain, ground fog |
| MicroVerse (Jason Booth) | Unity Asset Store | Terrain |
| Heat – Complete Modern UI (Michsky) | Unity Asset Store | Settings, popups and menu framework |
| Motion Titles Pack | Unity Asset Store | Animated titles |
| AMS UI Soft Mask | Unity Asset Store | Soft UI masks |
| UI SFX Mega Pack | Unity Asset Store | Menu sounds |
| PixPlays Elemental VFX | Unity Asset Store | Wind aura on rolls |

Without them, the game's own code in `Assets/_ShiftRush/` is still public and readable, but scenes show missing references. If the ARCADE pack is missing, the menu backdrop falls back to a plane built from simple shapes.
